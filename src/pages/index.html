What is different

It is the same game, made from the DOS game's own code and checked against it turn by turn. OpenCol only adds what makes it easier to play today, and nothing new is forced on you.

Runs today

No DOSBox, nothing to set up

Windows 10 and 11, macOS 11 or later; Linux from source. A window or full screen with F11.

The screen

More of the map

Larger screen sizes, UI Scale, and a World View that pans by the pixel and zooms out to the whole continent.

Settings

Everything in one place

Screen, volume sliders, edge scrolling and the original's game options, on five pages.

On the map

The map tells you more

The go-to route as you drag, action cursors, village notes and the Village Adviser.

Popups

Fewer of them

Founding Father cards, one Turn Report page, scrolling lists in place of pages, and Combat Analysis in full.

Rules

Rule options you choose

Where players disagree about a rule, you decide. At 0, every option is the original's rule.

Maps

The map editor, built in

Place resources, villages, units and start squares, then Play This Map in Game. Maps up to 228 squares a side.

Saved games

Your 1994 saves still load

Quick Save, ten turns of autosaves, and Exit to Main Menu. A save that cannot load says why.

The mission: one base, built together

OpenCol keeps Sid Meier's Colonization as it was, and lets the community take it further. A player who wants the 1995 game gets it. A player who wants more turns it on. Everyone builds on one shared base instead of each patching the game alone.

Every change is one of four kinds, and the kind decides whether it has a switch. Changes to the rules are decided with the community, in the open.

  1. An issue says what changes, and which kind it is.
  2. Discussion on the issue and on Discord: which variant, what the computer players do, the default.
  3. The maintainers decide and write the decision on the issue.
  4. The change is made and checked: with every option at 0, OpenCol still plays as the 1995 game.

3 · Play

Unpack and start

Unpack the zip where you can write (not in Program Files) and start opencol. The first time, it asks for your game's folder: the one with VICEROY.EXE in it.

macOS: OpenCol is not signed by Apple, so the first time, right-click opencol and choose Open. Upgrading: unpack the new version over the old folder.
